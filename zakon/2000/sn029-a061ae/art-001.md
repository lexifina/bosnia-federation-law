# Član 1.
U Zakonu o prekrsajima kojima se povredjuju federalni propisi
("Sluzbene novine Federacije BiH", broj 9/96) u clanu 27. stav 1. broj "500"
zamjenjuje se brojem "2.000". U stavu 2. broj "5.000" zamjenjuje se brojem
"10.000", a broj "1.000" zamjenjuje se brojem "2.000" U stavu 3. broj "10.000"
zamjenjuje se brojem "50.000", broj "2.000" zamjenjuje se brojem "5.000",
a broj "1.000" zamjenjuje se brojem "2.000". Stav 6. se brise, a dosadasnji
stav 7. postaje stav 6.
