# Član 26.
U članu 134. iza stava 2. dodaje se novi stav 3., koji glasi:
"Kada
se u federalnom zakonu ili drugom federalnom propisu daje ovlaštenje za donošenje
provedbenog propisa, odnosno općeg akta iz stava 2. ovog člana, moraju se bliže
odrediti pitanja koja će se tim propisom, odnosno aktom regulisati".
Dosadašnji stav 3. postaje stav 4.
